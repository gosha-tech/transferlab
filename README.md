# TransferLab

Футбольная аналитика и экспериментальная модель оценки трансферной стоимости.

**Состояние проекта:** сборка TransferLab 5.0 из архивного ZIP, 1 353 профиля / 11 лиг. Сведения о клубах, контрактах, фотографии и сезонная статистика могут быть неполными или устаревшими. Это не live-источник данных.

## Как работает сборка

- Исходный архив: `TransferLab_RESTORED_2026-11-16.zip`.
- Сборщик: `scripts/prepare.py` — создаёт `_site/index.html` и применяет исправления интерфейса.
- Стили: `assets/site.css`; улучшения доступности: `assets/site.js`.
- Автотест: `scripts/smoke.py`, проверяет поиск, профиль, сортировку и фильтрацию в браузере.
- Публикация: `.github/workflows/pages.yml`, GitHub Actions.

## Публикация

В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
В Actions запустите **Build and publish TransferLab** через **Run workflow**, если публикация не начнётся сама.

После успешного релиза сайт будет доступен по адресу: `https://gosha-tech.github.io/transferlab/`.

## Актуальность данных

Ежедневное автоматическое обновление реальной статистики **пока не подключено**. Для него нужен API-ключ провайдера футбольных данных, покрывающего нужные соревнования, и отдельная проверенная задача обновления. Без неё нельзя обещать свежие результаты или автоматически подтверждать трансферы.

Не вносите секреты API в публичные исходники или `index.html`. Используйте **Settings → Secrets and variables → Actions**.

## Ежедневное обновление статистики и турниров

1. Получите ключ на https://dashboard.api-football.com/
2. Откройте https://github.com/gosha-tech/transferlab/settings/secrets/actions
3. Нажмите New repository secret и укажите имя API_FOOTBALL_KEY (строго без пробелов).
4. Вставьте ключ в значение секрета. Не публикуйте ключ в README, сайте или чате.
5. Откройте https://github.com/gosha-tech/transferlab/actions/workflows/pages.yml и запустите Build and publish TransferLab через Run workflow. Далее запуск ежедневный, в 04:23 UTC.

Задача извлекает статистику API-Football по турнирам (АПЛ, ЛЧ, кубки, другие лиги), сохраняет data/live.json и встраивает данные в HTML сайта до его публикации. Новые игроки получают устойчивый API ID, поэтому дополнительные профили сохраняются при повторном обновлении.

Проверка: оба задания build и deploy должны завершиться с зелёными галочками. В профиле игрока можно выбрать соревнование. Отсутствующие показатели остаются пустыми, неполное покрытие прямо помечено.

Ограничение бесплатного API: 100 запросов в день и первые 3 страницы игроков для турнира; это НЕ полное покрытие чемпионатов и всех кубков. Для полного импорта требуется подходящий тариф и историческая дозагрузка.
Документация: https://www.api-football.com/documentation-v3
